## Learning Path

A practical progression is:

1. Begin with **NAT Trouble** and **Host-Only Lab Double Trouble** to understand the networking environment.
2. Continue with **Double Trouble Lab Setup** before exploring its hidden-path challenge.
3. Move into **Drip Deploy** and **Drip Trail Blue Room** to become familiar with the Drip lab theme.
4. Continue with **Drip Chain Blues** and the root-focused Drip challenges.
5. Study **Polkit Drip Escalation** and **Drip to Root PolicyKit Breakout** for the PolicyKit/Polkit security theme.

## How to Use the Labs

1. Open each lab through its direct Learn SecByte link.
2. Follow the supplied setup and scope instructions.
3. Perform activities only inside authorized lab environments.
4. Keep notes on network configuration, discoveries, clues, and security concepts.
5. Treat privilege-escalation exercises as controlled educational practice.
6. Review the underlying concept after completing each challenge.
